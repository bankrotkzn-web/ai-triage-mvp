# AI Triage Service (MVP)
Микросервис на FastAPI для первичной обработки обращений с помощью LLM (OpenAI).

## 🎯 Что делает этот проект
Проект решает задачу автоматизации техподдержки. Он принимает текст обращения пользователя, классифицирует его по категориям, генерирует черновик ответа с помощью ИИ и сохраняет всю историю в базу данных. В случае ошибки срабатывает механизм эскалации (передача живому оператору).

## 💻 Стек технологий
* Python 3.10+, FastAPI
* OpenAI API (gpt-4o-mini)
* SQLite (хранение истории)
* Docker (контейнеризация)

## 🚀 Как запустить
1. Склонируйте репозиторий.
2. Создайте файл `.env` и добавьте ключ: `OPENAI_API_KEY=ваш_ключ`
3. Соберите и запустите Docker-контейнер:
   `docker build -t ai-triage .`
   `docker run -p 8000:8000 --env-file .env ai-triage`

## 🔌 API Команды
**POST /triage**
Принимает JSON:
`{"text": "Проблема с оплатой", "channel": "email", "client_id": "user1"}`
