# AI Triage Service (MVP)
Сервис первичной обработки обращений с помощью LLM.

## Запуск через Docker (занимает 2 минуты)
1. Убедитесь, что у вас установлен Docker.
2. Создайте файл `.env` в корне проекта и добавьте ключ: `OPENAI_API_KEY=ваш_ключ`
3. Соберите образ:
   `docker build -t ai-triage .`
4. Запустите контейнер:
   `docker run -p 8000:8000 --env-file .env ai-triage`

## Проверка работы
Сервис будет доступен по адресу `http://localhost:8000/triage`.
База данных `tickets.db` создается автоматически при первом запуске.
